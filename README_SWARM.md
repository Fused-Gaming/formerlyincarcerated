## 🎓 Design Standards (Quick Reference)

### Colors (HP Brand)
- **Primary:** #F7931A (Orange) — CTAs, highlights
- **Text:** #050505 (Black) — 11.2:1 contrast minimum
- **Background:** #F6F1E8 (Cream) — light mode
- **All combinations:** WCAG AAA verified ✅

### Typography
- **Display:** Bebas Neue (36px-60px)
- **Body:** Inter (16px, 24px line-height)
- **Responsive:** `clamp()` functions

### Spacing
- **Unit:** 8px baseline
- **Scale:** 1, 2, 3, 4, 6, 8, 12, 16, 20, 24, 32
- **Used in:** Tailwind config
